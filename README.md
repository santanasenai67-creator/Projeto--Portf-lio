# Portfólio / Currículo Web

## Sobre o Projeto

Este projeto consiste no desenvolvimento de uma página de **Portfólio / Currículo Web** para um desenvolvedor. A página foi criada utilizando HTML5 puro, com foco na utilização correta de elementos semânticos e na organização das informações pessoais, habilidades, projetos e formas de contato.

O objetivo principal é demonstrar conhecimentos básicos de desenvolvimento web, principalmente na estruturação de páginas utilizando HTML semântico.

## Objetivo

Criar uma página HTML limpa, organizada e funcional, reproduzindo a estrutura apresentada no modelo proposto.

A página apresenta informações sobre o desenvolvedor, seus projetos, suas habilidades e um formulário para contato.

## Estrutura da Página

A página é dividida nas seguintes partes:

### Cabeçalho e Navegação

O cabeçalho apresenta o nome e o cargo do desenvolvedor.

Também possui um menu de navegação com links internos para as principais seções da página:

* Sobre Mim
* Meus Projetos
* Entre em Contato

Os links utilizam âncoras HTML, como `href="#sobre"` e `href="#projetos"`, permitindo a navegação entre as seções da própria página.

### Sobre Mim

A seção "Sobre Mim" apresenta uma breve descrição do desenvolvedor e uma foto de perfil.

A imagem possui as dimensões:

* Largura: 150px
* Altura: 150px

Também é apresentada uma lista contendo as principais habilidades do desenvolvedor.
